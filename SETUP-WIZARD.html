Step 1: Generate Icons (1 minute)

What you'll do: Generate 3 icon files needed by the extension.
After generating:
1. The 3 PNG files will download automatically
2. Move them from Downloads to your extension folder
3. Come back here and click "Next"

Step 2: Google Cloud Setup (5 minutes)

What you'll do: Get your secret key from Google so the extension can access Docs & Drive.

2A. Create Project

Create a project named "AI-Docs-Saver"

2B. Enable APIs

2C. Get Client ID

1. Click "Configure Consent Screen" → External → Create
2. Fill app name & your email → Save and Continue (3 times)
3. Create Credentials → OAuth client ID → Chrome Extension
4. Copy your Client ID (we'll use it next)

Step 3: Install in Chrome (2 minutes)

What you'll do: Load the extension into Chrome and connect it to Google.

3A. Load Extension

  • Turn on "Developer mode" (top-right toggle)
  • Click "Load unpacked"
  • Select your extension folder

3B. Get Extension ID

3C. Connect to Google

Paste your Extension ID in the "Application ID" field → Save

🎉 All Done!

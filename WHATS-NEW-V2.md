## ⚡ **Quick Save Button** (90% of your saves)

**What it does:**
- **ONE CLICK** → saved!
- Auto-generates doc name with timestamp
- Auto-detects 3 keyword tags from content
- Saves to your last-used folder (or root)
- Same speed as v1.0

**Example filename:**
```
machine_learning_tutorial_2025-11-22_14-30
```

**Perfect for:**
- Research sessions
- Learning new topics
- Quick references
- When you just want it saved NOW

**Speed**: 1 second total ⚡

## 📁 **Folder Management**

### **How Folders Work**

1. **First save**: Choose any folder (or use root)
2. **Second save**: Extension remembers your choice
3. **Quick Save**: Auto-uses last folder
4. **Custom Save**: Pick different folder anytime

### **Folder Dropdown Shows:**
- ⭐ **Recent folders** (top 5 you've used)
- 📂 **All your folders** (alphabetical)
- 📂 **My Drive (Root)** (always available)

### **Pro Tip:**
Save once to your favorite folder, then Quick Save uses it automatically!

## 🚀 **Upgrading from V1 to V2**

### **If You're Installing Fresh**
- Just follow QUICKSTART.md
- You'll get V2 by default

### **If You Have V1 Installed**

**Option 1: Keep V1** (if you prefer simplicity)
- No action needed
- V1 still works fine

**Option 2: Upgrade to V2** (recommended!)

1. **Update manifest.json**:
   - Change `"version": "1.0.0"` → `"2.0.0"`
   - Already done if you pull latest code

2. **Reload extension**:
   - Go to `chrome://extensions/`
   - Click reload button on your extension

3. **First use**:
   - Click Quick Save → sets your default folder
   - Now all Quick Saves go there!

4. **Learn organization**:
   - Read ORGANIZATION-GUIDE.md
   - Set up your folder structure
   - Start using tags

**Upgrade time**: 2 minutes

## ❓ **FAQ**

**Q: Do I have to use folders and tags?**
A: Nope! Quick Save works without any organization. Tags are optional.

**Q: Can I still use the old v1.0 behavior?**
A: Yes! Quick Save = exactly the same as v1.0 (1-click, done)

**Q: What if I don't want auto-tags?**
A: Just clear them in Custom Save. Quick Save adds them but they're optional.

**Q: How many folders can I have?**
A: Unlimited! The dropdown shows your 20 most recent.

**Q: Can I search by tags in Google Drive?**
A: Yes! Search: `"Tags: your-tag"` or `type:document "your-tag"`

**Q: Does this slow down saving?**
A: Quick Save = same speed as v1.0 (1 second). Custom Save = 5-10 seconds.

**Q: Can I edit tags after saving?**
A: Not yet in the extension, but you can edit the doc directly in Drive.
